# HashBreaker

## Baixar para Windows

[Baixar o instalador do HashBreaker](https://github.com/marcos-213/HashBreaker-Updates/releases/download/v0.5.0-beta.1/HashBreaker-Instalacao-Windows-x64.zip)

1. Baixe e extraia o arquivo ZIP.
2. Abra **Launcher HashBreaker.exe** na pasta extraída.
3. Para as próximas versões, use o atualizador do launcher.

Versão disponível: **0.5.0-beta.1** (beta).
